# 🐉 Dragones Inestables · GEM

Juego de cartas en línea del **GEM · Grupo Estudiantil de Matemática** (Facultad de Ciencias, UNI).

- Abre el enlace del juego, escribe tu nombre y crea una sala o únete con su código de 4 letras.
- También puedes jugar solo contra bots (Fácil, Normal o Difícil).

Servidor: Node.js + Socket.IO (`node server.js`). Desplegado en Render (plan gratuito).
